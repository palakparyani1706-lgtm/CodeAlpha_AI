# 🌐 Language Translation Tool (AI Internship Project)

## 📌 Overview
This is a Language Translation web application built as part of my AI Internship at CODSOFT.  
It allows users to enter text, select source and target languages, and get instant translated output using a translation API.

---

## 🧠 How It Works
User enters text → selects source & target languages → text is sent to a translation API (Google Translate / Microsoft Translator) → API returns translated text → result is displayed on screen.

---

## ✨ Features
- 🌍 Translate text between multiple languages  
- 🎯 Select source and target language  
- ⚡ Instant translation using API  
- 📋 Clean and simple user interface  
- 📄 Easy-to-read translated output  
- 📌 Optional copy button / text-to-speech support  

---

## ⚙️ Technologies Used
HTML, CSS, JavaScript, Translation API (Google Translate / Microsoft Translator)

---

## ▶️ How to Run
Open `index.html` in any web browser and start using the translator.

---

## 📁 Files
index.html, script.js, style.css

---

## 🎯 Objective
To build a simple AI-based language translation tool using APIs and understand how real-time translation systems work.
