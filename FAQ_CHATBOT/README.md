# 🤖 FAQ Chatbot (AI Internship Project)

## 📌 Overview
This project is an FAQ Chatbot built as part of my AI Internship at CODSOFT.  
It answers user questions by matching them with the most relevant FAQs using NLP techniques like preprocessing and similarity matching.

---

## 🧠 How It Works
User enters a question → text is cleaned and preprocessed → question is compared with stored FAQs → most similar question is found using cosine similarity → best matching answer is displayed.

---

## ✨ Features
- FAQ-based chatbot system  
- NLP preprocessing (tokenization, cleaning, etc.)  
- Cosine similarity for matching questions  
- Intelligent response selection  
- Simple web-based UI (HTML + CSS)  

---

## ⚙️ Technologies Used
Python, NLP (NLTK / SpaCy), JSON, HTML, CSS, Cosine Similarity

---

## ▶️ How to Run
Run the main file:
python app.py

Then open index.html in browser for UI (if used).

## 📁 Files

## 🎯 Objective
To build a simple AI-based chatbot that can answer FAQ-style questions using NLP and similarity matching techniques.
