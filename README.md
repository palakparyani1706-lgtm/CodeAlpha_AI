# 🤖 AI Internship Projects - CodeAlpha

## 📌 Overview
This repository contains my **AI Internship projects at CodeAlpha**.  
It includes 3 AI-based tasks covering APIs, Natural Language Processing, and Computer Vision.

Each project is organized in separate folders with its own implementation and README.

---

## 📁 Projects Included

### 1️⃣ Language Translation Tool (API Project)
📂 Folder: `Language-Translation-Tool`

A web-based application that translates text between multiple languages using a translation API.

#### ✨ Features:
- Translate text between multiple languages  
- Source and target language selection  
- Real-time translation using API  
- Simple web interface  

#### 🧠 Tech Stack:
HTML, CSS, JavaScript, Translation API

---

### 2️⃣ FAQ Chatbot (NLP Project)
📂 Folder: `FAQ-Chatbot`

An AI-based chatbot that answers frequently asked questions using Natural Language Processing techniques.

#### ✨ Features:
- FAQ-based question answering system  
- Text preprocessing and cleaning  
- Cosine similarity for matching questions  
- Intelligent response selection  

#### 🧠 Tech Stack:
Python, NLP, NLTK / SpaCy, JSON

---

### 3️⃣ Object Detection & Tracking (Computer Vision Project)
📂 Folder: `Object_Detection_And_Tracking`

A real-time object detection and tracking system using YOLOv8 and SORT algorithm.

#### ✨ Features:
- Real-time object detection using webcam/video  
- Object tracking with unique IDs  
- Bounding box visualization  
- Fast and efficient processing  

#### 🧠 Tech Stack:
Python, OpenCV, YOLOv8, SORT, NumPy
